- **Slide error:** The slide says for `RXC0`: "0 → data reception is in progress". Correct: `RXC0` = 0 means there is **no unread byte**. Usually nothing is arriving at all.
- **Slide error:** The title of slide 9 says "USCR0C". The register is `UCSR0C`. Slides 6 and 8 write "UDRE", "RXEN" and "TXEN" without the 0. In C code the names are `UDRE0`, `RXEN0` and `TXEN0`.
- **Watch out:** - `transmitByte` waits for `UDRE0`, `receiveByte` waits for `RXC0`. Swapping them is a classic bug. - If `TXEN0` is not set, nothing appears on TxD. - The receive buffer holds only 2 bytes. If the program is busy for long (a `_delay_ms(1000)`), bytes are lost.
- **Watch out:** `if (data_rcvd == '1')` compares. `if (data_rcvd = '1')` assigns and is always true.
