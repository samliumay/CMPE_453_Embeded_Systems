## Known errors and traps in the sources (do not teach the errors)

- **Watch out:** The compiler only makes a file on the laptop. Nothing reaches the chip until the flash programmer copies it. "Done compiling" with no board connected is normal.
- **Slide bug:** The slide writes "Atmega328p: address range 0x0000-0x3FFF" right after the byte address 0x7E00. That range is in **words**. In bytes the flash is 0x0000-0x7FFF, so 0x7E00 is a valid byte address. Also: the three pictures on slide 4 come from different files. T...
- **Watch out:** `|=` can only turn bits on. To turn a bit off use `&=` with a 0 in the mask: `PORTB &= 0b11111110;`. The loop's `PORTB = ...` overwrites all of port B. That is fine here only because nothing else is on port B.
