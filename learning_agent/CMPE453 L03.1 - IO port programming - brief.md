## Known errors and traps in the sources (do not teach the errors)

- **Watch out:** Count bits from the **right**, starting at 0. `=` overwrites all 8 bits. Single-bit changes need `|=` and `&=` ([[CMPE453 L03.2 - Bitwise operations]]).
- **Watch out:** - "1 puts Vcc on the pin" holds only for an **output** pin. On an input pin a 1 in `PORTx` switches on the pull-up. - The ATmega328P has no PC7. On the Uno PC6 is the RESET pin, so in the slide example only PC3 (A3) goes high. Use PC0-PC5 on a Uno.
- **Watch out:** Read inputs from `PINx`. Reading `PORTx` gives back what you wrote, not what is on the pins.
- **Watch out:** After PD7 the light jumps back to PD0, it does not walk back. On the Uno PD0 and PD1 are also RX/TX of the USB link: if uploading fails, unplug those two wires.
- **Watch out:** - Slide 13's comment says "read from PINB". The code reads `PINC`, which is correct. - `if (temp = 100)` assigns and is always true. Compare with `==`. - Real chip: port C has no PC7, so in Exercise 2 bit 7 is lost (`0xFF` appears as `0x7F`). Unconnected input...
